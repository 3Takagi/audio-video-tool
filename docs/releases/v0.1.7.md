# 音视频工具 0.1.7

- 修复 YouTube 下载环境：更新 yt-dlp、EJS 配套脚本，并自动补齐支持的 Node 运行时。
- 调整 YouTube 下载为 1 MiB 小块请求，已用问题链接完成 3840 x 2160 视频与音频的完整下载和合并验证。
- 增加启动时自动维护下载组件：成功后 24 小时内不重复检查，失败后 6 小时再尝试。
- 下载组件在独立目录中安装并校验，下载失败不会替换正在使用的版本，也不会更新图片超分依赖。
- 兼容已有 0.1.0 桌面壳：获取本次后端补丁后即启用自动维护，无需重新安装模型。

## 更新方法

已有桌面版：完全退出后重新启动，程序将检查最新后端补丁；首次下载组件更新可能需要一两分钟。

便携版：下载最新 `AudioVideoTool-Portable-Python.zip`，解压后运行 `start.bat`，会复用已配置的共享环境。

需要立即更新：下载并解压 `AudioVideoTool-Patch.zip`，在解压目录运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\update.ps1`，完成后重启程序。

`AudioVideoTool-Desktop-Setup-0.1.0.exe` 是桌面壳安装包，壳版本未变，后端当前版本为 0.1.7。自动检查在启动时执行，需要联网；平台规则或运行环境发生较大变化时仍可能需要应用补丁。

## English

Backend 0.1.7 updates yt-dlp and EJS, supplies a supported JavaScript runtime, and uses smaller YouTube download chunks. Downloader maintenance now runs at startup, at most once every 24 hours after success or once every six hours after failure. Packages are staged and validated in an isolated directory before activation. Existing desktop shell 0.1.0 can receive this backend through content patches. Restart the app after updating; portable users can extract the new ZIP and run `start.bat` to reuse their existing environment.
